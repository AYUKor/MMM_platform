# Past campaigns tab — Review Notes

## Evidence boundary

The PNG files below use the synthetic catalog fixture
`frontend/src/test/fixtures/campaign_catalog_v1_synthetic.json`, built by the
real catalog service from `mmm_core.campaign_catalog_synthetic`. Campaign
names are «Тестовая кампания N». They verify presentation states only and are
not evidence of real model numbers. Orders, basket and geography of the
fixture follow the magnitudes of the real Заноза catalog of 2026-11-05: orders
per 1000 buyers from thousandths to about ten, an average basket that moves by
less than a kopeck in most campaigns, and regions listed next to cities.

Generated by `frontend/e2e/campaign-catalog.visual.spec.ts` with API route
interception; the spec fails on any request outside the catalog endpoints.

## Review checklist

- [x] Layout follows the accepted mock-up v2 of 2026-10-28.
- [x] Header shows the model, data end date, campaign count, ROAS of all
      campaigns and the ROAS level label.
- [x] Excel button only for roles with `report.download`.
- [x] Filters live in the address bar; the card keeps them for the way back.
- [x] Campaigns without an estimate show «нет оценки», never zeros.
- [x] Card shows estimate and «от … до» for four effects with reference
      points 0 and 1,0.
- [x] No model identifiers, channel ids or package ids on screen.
- [x] No horizontal scroll at 390 px.
- [x] Small effects keep about two significant digits: orders up to
      thousandths, basket in kopecks («меньше копейки» when the whole range is
      under half a kopeck), money in millions up to four decimals.
- [x] Geography counts regions apart from cities.

## Departures from the mock-up

- Per-channel dates and city counts in «Каналы и бюджет» are replaced by the
  budget share bar: the catalog has no per-channel dates.
- The list of overlapping campaigns on the card is replaced by their count:
  the catalog publishes the count only.
- «Города» is renamed «География»: the real geography lists 61 regions
  (oblasts, krais, republics) next to 162 cities.
- The mock-up showed orders and basket with one decimal; real effects are
  hundreds of times smaller, so decimals follow the size of each range.
